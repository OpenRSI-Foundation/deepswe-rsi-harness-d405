# Discovery validation entry

Read [Discovery execution validation](science-execution-validation.md) as the
complete procedure for Scientific Discovery and existing model-access rubric
packages. It includes setup, environment acceptance, computation checks, Judge
assertions, bounded fixed-submit acceptance and handoff. Use the selected
backend's tools; no General validation workflow is required.

The integrity audit needs a supported model Agent. Oracle does not provide this
backend. Follow the bounded validation instruction rather than launching research.
Reuse confirmed platform, resource and model-cost authorization; resolve only
missing decisions. A validation-only request ends with the report, and source
and evidence remain local unless publication was authorized.
