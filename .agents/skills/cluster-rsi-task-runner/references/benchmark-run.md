# Benchmark run and outcome

Use General's execution loop with the approved proposal's maximize/minimize
direction and materialized-candidate evaluator. No rubric library or Judge-model
credential is required. Preserve validated network and hidden-evaluator boundaries.
Do not stop merely because validity checks pass: use the authorized budget and
explicit stopping rule. Reuse the backend's normal scheduling and recovery.

After the final trajectory audit and
[scientific re-verification](scientific-reverification.md), report raw best score
and effective score/eligibility separately. Confirmed misconduct makes the run ineligible; do not replace a metric
with a potentially winning zero. Explain the candidate, metric/units, matched
reference, validity evidence, uncertainty and scientific limits. A better metric
is not proof of an unrelated mechanism or global optimality. No completed evaluation
means no verified best result. Follow the runner's shared completion report and
publication authorization; do not launch new research or announce a world record.
